# Технический долг

Осознанные компромиссы, которые не блокируют текущую итерацию, но должны быть закрыты до
публичного релиза или при следующем касании соответствующего кода. Список пополняется по мере
упрощений; каждый пункт называет, **почему** он существует и **что** нужно сделать.

## Схема и данные

1. **`SourceEntity` всё ещё описывает VOD-эру.** DTO больше не содержит `syncMovies`/`syncSeries`
   (вычищены вместе с VOD), но остались `isPaid`, `createdAt` (читателей нет), а также
   `httpReferer` и `syncLive` — они ещё читаются, хотя у единственного источника всегда
   `syncLive = true`, а `httpReferer` пуст. *Закрыть:* убрать мёртвые поля и свести два читаемых
   к константам `BuiltInSource`, когда последний читатель уйдёт.
2. **`ChannelEntity` — 15 геттеров-синонимов** (`catchup*`, `httpHeaders`, `drmConfig`,
   `manifestType`, `directSource`, `providerName`, `isPaid`, `id`, `epgChannelId`, `sourceId`,
   `streamUrl`). Это компенсирует удалённые из БД колонки; ~700 read-site'ов ещё используют
   синонимы. *Закрыть:* переписать чтения на реальные поля/константы и удалить геттеры.
3. ~~**`EpgProgrammeEntity.contentHash` всегда 0**~~ — закрыто в v8: колонка удалена вместе с
   `year`/`episode`/`lengthMin`.
4. **`mediaType` в коде.** Из БД колонка удалена (v6), но `MediaType.LIVE` остаётся параметром
   многих API (`CustomizationStore`, `LiveKey`, `SettingsRepository.observe*`) как жёстко
   зашитый LIVE. Это осознанно: один тип контента. *Закрыть:* только если появится второй тип
   контента; до тех пор не плодить новые `mediaType`-поля.
5. **`tv_provider_programs` — спящая таблица.** DAO зарегистрирован в Koin, production-вызовов
   записи/чтения нет (интеграция с домашним экраном Android TV демонтирована). *Закрыть:*
   удалить таблицу/DAO или вернуть фичу.
6. **`SingleSource.id = 1` — константа**, хотя `sourceId` больше нигде в БД нет. Осталась
   пространством имён ключей кастомизации (`<sourceId>:<remoteId|name>`) и синонимом
   `ChannelEntity.sourceId`; playback `contentKey` — уже просто hex. *Закрыть:* вместе с п.2
   (тогда ключи кастомизации станут `<remoteId|name>`, а константа исчезнет).
7. **Деструктивная миграция** `fallbackToDestructiveMigration(dropAllTables = true)` — временная
   мера периода редизайна. *Закрыть:* убрать строку и написать миграции до публичного релиза.

## Код, оставшийся от мультиисточниковой эпохи

8. **`ActiveProfileSources` / `activeProfileSources()`** — теперь всегда список из одного DTO;
   имя и форма остались от профилей/плейлистов. *Закрыть:* заменить на прямое чтение
   `BuiltInSource` в вызывающих экранах.
9. **`SourceRepository.observeSources()` возвращает `List<SourceEntity>` из одного элемента**, а
   `currentSource()` собирает DTO из `sourcePreferences`. *Закрыть:* вместе с п.8 — один
   `Flow<SourceEntity>` без списка.
10. **UI «переопределений для плейлиста»** (пре-буфер, задержка, «give up after», чистка имён):
    строки остались, но пишут глобальные настройки, а DTO отдаёт sentinel «follow global», когда
    значение равно дефолту. Поведение корректное, но строки дублируют глобальные. *Закрыть:*
    удалить per-playlist-строки из `VideoPlayerSettingsScreen`.
11. **`ChannelNameCleanupDialog`/`ChannelNameCleanupViewModel` недостижимы** (нет вызова host-
    композабла), но сохранены и пишут глобальные ключи `channel_cleanup_*`. *Закрыть:* удалить
    UI (ядро `ChannelNameCleanup` можно оставить для будущего).
12. **`ResyncChoiceDialog` и `EpgSyncScheduler.enqueueSync` не имеют вызывающих** — ручного
    ресинка и отдельного планировщика EPG в UI больше нет. *Закрыть:* удалить мёртвый код или
    вернуть точку входа «Обновить каталог».
13. **`GuidePriority` — no-op обёртка** вокруг `EpgDedupe` (один guide-store). Оставлена как
    шов на случай второго фида. *Закрыть:* удалить и звать `EpgDedupe` напрямую.
14. ~~**`EpgRepository.clear()` без вызывающих**~~ — закрыто: метод удалён вместе с multi-source
    остатками; гид чистится только ретенцией синка.

## Пользовательские данные и синхронизация

15. **Напоминания больше не хранят имя канала** (v6): prompt показывает только время и название
    передачи. *Закрыть:* при желании подтягивать имя из `channels` по `channelId` на экране
    напоминания (один запрос при показе).
16. **`HistoryDeviceStamp` читает `ANDROID_ID` через глобальный Koin-контекст**, а при неудаче
    пишет ключ `""`. *Закрыть:* передать `DeviceIdentity` в DAO-слой явно или через конструктор
    репозитория.
17. **`contentKey` для строк без provider id — это URL** (fallback). Для RuTube таких строк нет,
    но код и хранилища всё ещё поддерживают URL-ключи. *Закрыть:* убрать fallback, когда
    последний не-hex контент исчезнет.
18. **Локальный sync-протокол упрощён** (нет `t`/`src` в записях, `prog` идентифицируется
    `(channelId, startMs)`). Совместимость со старыми сборками не поддерживается — это окно
    полного реинсталла. *Закрыть:* ничего; при появлении разнородных версий — версионировать
    payload.
